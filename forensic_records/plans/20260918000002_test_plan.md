# Test Plan: 20260918000002_fix_invitations_anon_grant

## Objective
Verify that `anon` and `authenticated` roles can query active invitations, enabling the `AcceptInviteScreen` to correctly validate invitation tokens without throwing "Convite Inválido" errors for valid tokens.

## What is being tested
1. **Grant verification:** `anon` role has `SELECT` privilege on the `public.invitations` table.
2. **Grant verification:** `authenticated` role has `SELECT` privilege on the `public.invitations` table.
3. **RLS validation (anon):**
   - Can see active/pending invitations (not expired, not revoked, not accepted).
   - Cannot see expired invitations.
   - Cannot see revoked invitations.
   - Cannot see accepted invitations.
4. **RLS validation (authenticated non-admin):**
   - Can see active/pending invitations.
   - Cannot see expired/revoked/accepted invitations (the admin policy does not apply since role is not TENANT_ADMIN).
