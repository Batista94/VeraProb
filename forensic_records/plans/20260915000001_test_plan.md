# Forensic Test Plan: Tenant Roles (20260915000001)

## Context
Refactoring the `roles:manage` monolithic permission into three distinct permissions: `users:manage`, `roles:read`, and `org:manage`. Also introducing 4 default profiles for each organization.

## Scope
- Validation of `tenant_permissions` insertions.
- Validation of retroactive seeding for existing orgs.
- Validation of new org creations having 4 profiles.

## Assertions
1. `users:manage`, `roles:read`, and `org:manage` exist in `tenant_permissions`.
2. Existing orgs have the 4 default profiles in `tenant_roles`.
3. The profiles have the correct mapping of permissions (e.g. Administrador has all 13).
4. `super_admin_create_organization` spawns the profiles automatically.
