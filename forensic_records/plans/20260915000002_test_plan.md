# Forensic Test Plan: Default Tenant Roles (20260915000002)

## Context
Validates that new organizations created via `super_admin_create_organization` get the 4 default profiles (Administrador, Validador, Auditor, Operador) seeded, and that retroactive seeding for existing orgs works as expected.

## Scope
- Validation of new org creations having 4 profiles.
- Validation of exact permission sets for the 4 profiles.

## Assertions
1. Existing orgs have the 4 default profiles in `tenant_roles`.
2. The profiles have the correct mapping of permissions (e.g. Administrador has all 13).
3. `super_admin_create_organization` spawns the profiles automatically.
