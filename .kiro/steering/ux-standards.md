# UX Standards - VeraProb

## Design System: Industrial Dark
The VeraProb interface follows a premium, high-density industrial aesthetic.

### 1. Visual Language
- **Theme**: Deep Dark Mode (Primary background: #0A0A0A).
- **Effects**: Subtle glassmorphism, 1px borders for separation.
- **Color Palette**: 
  - Action: #00A3FF (Industrial Blue)
  - Critical: #FF3B30 (Alert Red)
  - Success: #34C759 (Safety Green)
  - Text: #E5E5E5 (High contrast)

### 2. Layout & Typography
- **Grid**: Strict 8pt spacing system.
- **Typography**: Inter for UI elements, Outfit for headings.
- **Icons**: Outlined, 20px/24px standard.

### 3. Micro-interactions
- **Feedback**: Immediate visual confirmation for all actions.
- **Animations**: Duration < 200ms, easing: cubic-bezier(0.4, 0, 0.2, 1).
- **Empty States**: Must use illustrative graphics (generate with tool).

### 4. Accessibility
- **Contrast**: WCAG AAA for text.
- **Touch**: Minimum 44x44pt hit targets.
- **Focus**: Clear, high-visibility focus rings.
